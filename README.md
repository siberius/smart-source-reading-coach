# Source Reading Coach

The student interprets a short primary source and supports their reading with a specific passage. For secondary school humanities work.

## How to use

1. Open the [English prompt](en/source-reading-coach.md) and paste it into a new chat.
2. Provide level, an anonymised source with its identifier, the learning objective and available time.
3. Review the draft and edit the document. Downloadable DOCX depends on the chat's file tools. The fallback is Markdown for a word processor.

In literary mode, learners interview a character and look for evidence for each reply in the excerpt.

## Example

Two contemporary reports of the same event. The student identifies evaluative wording and explains how the accounts differ.

## Status and privacy

Version 1.2.0. Model behaviour and file generation have no documented test yet. The repository contains a written workflow. The chosen chat provider handles your materials. Use public or anonymised sources.
